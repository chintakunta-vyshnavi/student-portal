# StudentPortal

StudentPortal is a student management web application built using FastAPI, SQLAlchemy, SQLite, and Jinja2.

## Features

- Student Registration
- Secure Login
- Password Hashing using Argon2
- Student Dashboard
- Admin-only Page
- Session-based Authentication
- Logout

## Technologies Used

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Jinja2
- HTML
- CSS
- Argon2
